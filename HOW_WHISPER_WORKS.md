# Whisper UI - Руководство по работе приложения

## Что такое Whisper UI

Whisper UI — это веб-приложение для автоматического преобразования речи в текст (транскрибации). Приложение использует технологию OpenAI Whisper — современную нейросетевую модель распознавания речи, обученную на 680 000 часов аудиоданных.

Приложение предоставляет удобный веб-интерфейс для работы с Whisper, избавляя пользователя от необходимости использовать командную строку или писать код.

---

## Основные возможности

### 1. Транскрибация аудиофайлов

Пользователь может загрузить аудиофайл с компьютера, и приложение автоматически преобразует речь в текст.

**Поддерживаемые форматы аудио:**
- MP3
- M4A
- WAV
- FLAC
- OGG
- WebM

### 2. Транскрибация видеофайлов

Приложение также поддерживает видеофайлы. При загрузке видео, система автоматически извлекает аудиодорожку с помощью FFmpeg и затем выполняет транскрибацию.

**Поддерживаемые форматы видео:**
- MP4
- AVI
- MOV
- MKV
- WMV

### 3. Работа с YouTube видео

Пользователь может указать ссылку на YouTube видео. Система загрузит аудиодорожку и выполнит транскрибацию. Поддерживаются различные форматы ссылок YouTube:
- Стандартные видео (youtube.com/watch?v=...)
- Короткие ссылки (youtu.be/...)
- YouTube Shorts
- YouTube Live
- YouTube Music
- Мобильные версии

**Функция обрезки:** перед загрузкой можно указать временной диапазон (начало и конец), чтобы транскрибировать только нужный фрагмент видео.

## Модели Whisper

Приложение поддерживает 5 различных моделей, отличающихся размером и точностью распознавания:

| Модель | Размер | Скорость | Требования RAM | Качество |
|--------|--------|----------|----------------|----------|
| **Tiny** | 39 MB | ~32x realtime | ~1 GB | Базовое |
| **Base** | 74 MB | ~16x realtime | ~1 GB | Хорошее |
| **Small** | 244 MB | ~6x realtime | ~2 GB | Очень хорошее |
| **Medium** | 769 MB | ~2x realtime | ~5 GB | Отличное |
| **Large** | 1550 MB | ~1x realtime | ~10 GB | Максимальное |

**Рекомендации по выбору модели:**
- **Tiny/Base** — для быстрой черновой транскрибации или когда ресурсы ограничены
- **Small** — оптимальный баланс скорости и качества для большинства задач
- **Medium** — для качественной транскрибации, когда время не критично
- **Large** — максимальная точность для профессиональных задач

## Процесс транскрибации

### Обычный режим (файлы до 10 минут)

1. Пользователь загружает файл или указывает YouTube ссылку
2. Выбирает модель Whisper и язык
3. Нажимает кнопку "Транскрибировать"
4. Модель загружается в память (при первом использовании)
5. Аудио передается в модель Whisper
6. Результат возвращается пользователю в виде текста и сегментов с таймкодами

### Режим чанков (файлы более 10 минут)

Для длинных аудиозаписей применяется специальный алгоритм разбиения:

1. Аудиофайл разбивается на фрагменты (чанки) по 5 минут
2. Между фрагментами создается перекрытие в 5 секунд для корректной склейки
3. Каждый чанк обрабатывается отдельно
4. Результаты объединяются с корректировкой временных меток
5. Перекрывающиеся сегменты удаляются для избежания дублирования

Это позволяет обрабатывать аудиозаписи любой длительности без переполнения памяти.

## Вывод результатов

### Текстовый результат

После завершения транскрибации пользователь получает:
- **Полный текст** — весь распознанный текст единым блоком
- **Сегменты с таймкодами** — текст разбит на фрагменты с указанием начала и конца каждого сегмента

### Форматы экспорта

Результат можно экспортировать в различных форматах:

1. **TXT** — простой текстовый файл без форматирования
2. **SRT** — формат субтитров с таймкодами (для видеоплееров)
3. **JSON** — структурированные данные с полной информацией о сегментах

## GPU-ускорение

Приложение автоматически определяет наличие совместимой видеокарты NVIDIA с поддержкой CUDA. При наличии GPU:

- Модель загружается в видеопамять
- Обработка выполняется на GPU (значительно быстрее)
- Используется FP16 (16-битные вычисления) для экономии памяти

**Пример производительности на RTX 3090:**
- Tiny модель: ~32x realtime (1 час аудио за ~2 минуты)
- Base модель: ~16x realtime
- Medium модель: ~2x realtime

При отсутствии GPU обработка выполняется на CPU, что значительно медленнее, но работает на любом компьютере.

## История транскрибаций

Все выполненные транскрибации сохраняются в локальной базе данных. Пользователь может:

- Просматривать историю с пагинацией
- Искать по названию или содержимому текста
- Фильтровать по типу источника (файл/YouTube) или языку
- Открывать полную версию любой транскрибации
- Удалять отдельные записи или выбранные группой
- Экспортировать несколько записей одновременно

Для каждой записи сохраняется:
- Дата и время создания
- Исходный файл или URL
- Распознанный текст
- Сегменты с таймкодами
- Использованная модель
- Время обработки
- Информация о YouTube видео (если применимо)

## Интерфейс приложения

### Три основные вкладки

1. **Завантажити файл** — drag-and-drop зона для загрузки аудио/видео файлов
2. **YouTube відео** — поле для ввода ссылки YouTube с предпросмотром информации
3. **Аудіотека** — библиотека ранее загруженных аудиофайлов

### Панель настроек

После выбора источника появляется панель с настройками:
- Выбор модели Whisper
- Выбор языка
- Информация о выбранном файле
- Кнопка запуска транскрибации

### Индикация прогресса

Во время обработки отображается:
- Процент выполнения
- Текущий этап (загрузка, обработка, транскрибация)
- Время обработки
- Для длинных файлов — номер текущего чанка

## Функция обрезки YouTube видео

При работе с YouTube видео доступна опциональная функция обрезки:

1. После получения информации о видео появляется панель обрезки
2. Пользователь включает режим обрезки
3. Устанавливает начало и конец нужного фрагмента:
   - Через текстовые поля с таймкодами
   - Через визуальный слайдер
   - Из встроенного видеоплеера (установка текущей позиции)
4. Система показывает итоговую длительность и сколько будет пропущено
5. При загрузке скачивается только выбранный фрагмент

Это позволяет:
- Экономить время на загрузку и обработку
- Транскрибировать только нужную часть длинного видео
- Игнорировать вступления, заставки и другие ненужные части

## Требования к системе

### Обязательные
- Python 3.8 или выше

- 8 GB RAM (для моделей medium/large рекомендуется больше)

## Безопасность

Приложение реализует следующие меры безопасности:

- **Валидация файлов** — проверка расширений и типов файлов
- **Защита от Path Traversal** — контроль путей сохранения файлов
- **Параметризованные SQL-запросы** — защита от SQL-инъекций
- **Ограничение размера файлов** — предотвращение DoS-атак
- **Безопасные имена файлов** — очистка имен от опасных символов

## Сценарии использования

### Сценарий 1: Транскрибация лекции

1. Записать лекцию на диктофон (MP3/M4A)
2. Загрузить файл через веб-интерфейс
3. Выбрать модель "Medium" для хорошего качества
4. Указать язык лекции
5. Получить текст с разбивкой по сегментам
6. Экспортировать в TXT для дальнейшей работы

### Сценарий 2: Субтитры для видео

1. Указать ссылку на YouTube видео
2. При необходимости обрезать ненужные части
3. Выбрать модель "Small" или "Medium"
4. После транскрибации экспортировать в SRT
5. Использовать SRT-файл как субтитры

### Сценарий 3: Быстрый поиск по видео

1. Указать YouTube ссылку
2. Использовать модель "Base" для скорости
3. Получить текст
4. Искать нужную информацию по тексту
5. По таймкодам сегментов найти нужный момент в видео

## Управление моделями

### Загрузка моделей

При первом использовании модель автоматически загружается из интернета и сохраняется в кэш (`~/.cache/whisper`). Повторные использования модели происходят мгновенно.

Также можно заранее загрузить нужные модели через интерфейс настроек.

### Переключение между моделями

При смене модели:
1. Текущая модель выгружается из памяти
2. Освобождается GPU-память (если использовалась)
3. Загружается новая модель
4. Это занимает несколько секунд

Рекомендуется использовать одну модель для серии транскрибаций, чтобы избежать повторных загрузок.
