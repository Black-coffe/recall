# Phase 13B: local embeddings for semantic RAG search of the archive (Meeting Memory).
# Default model: intfloat/multilingual-e5-large (1024-dim, UA/RU, safetensors).
# The first use pulls ~2.2GB into ~/.cache/huggingface. Runs on an RTX 3090.
#
# CRITICAL PINS — a chain of incompatibilities with our torch 2.5.1+cu121 (each verified):
# 1. sentence-transformers 5.x → pulls torchcodec, whose native DLLs do NOT load
#    on torch 2.5.1 (libtorchcodec_core*.dll FileNotFound) → the import fails. → 3.x.
# 2. transformers 5.x → requires huggingface_hub>=1.0, which BREAKS the pyannote pin
#    (hub 1.x removed use_auth_token=). We keep <5 → hub stays 0.36.x (<1.0).
# 3. transformers>=4.56 blocks torch.load(.bin) on torch<2.6 (CVE-2025-32434).
#    So EMBED_MODEL must have safetensors. bge-m3 has ONLY pytorch_model.bin →
#    not suitable; e5-large has model.safetensors → OK. use_safetensors=True in the code.
sentence-transformers==3.4.1
transformers>=4.41,<5
